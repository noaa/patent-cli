# Prompt 6: 패밀리 트리 분석 + 환경 점검

## The Prompt

> US8725880B2의 해외 패밀리가 어느 나라에 등록되어 있는지 한눈에 보고 싶어.
> 표 형태로 `./family.tsv`에 저장해주고, 혹시 내 `gp-cli`가 최신 버전인지도
> 같이 확인해줘. 그리고 이 도구가 어떤 필드들을 지원하는지도 간단히 알려줘.

## What This Tests

- `family-group` 명령으로 다중 특허(여러 국가)를 한 번에 처리하고
  `--format tsv --output-dir`로 결과를 저장하는 흐름
- `update --check`(또는 동등 기능)로 설치된 버전과 최신 버전을 비교하는 보조 작업
- `fields` 명령으로 지원 필드 목록을 조회해 사용자에게 요약하는 능력
- 서로 다른 성격의 하위 작업(데이터 수집 / 환경 점검 / 문서 조회)을 한 세션에서
  순서대로 처리하는 조합 능력

## Expected Behavior

1. `gp-cli family-group US8725880B2 --format tsv --output-dir .`로 패밀리 데이터 저장
   (결과 파일을 사용자가 요청한 `family.tsv` 이름/위치로 정리)
2. `gp-cli update --check`로 버전 확인 (실행 불가 환경이면 그 사실을 알림)
3. `gp-cli fields`로 지원 필드를 조회하고 핵심 카테고리만 요약
4. 세 가지 결과를 하나의 보고서로 종합

## Pass Criteria

- 패밀리 데이터가 국가별로 구분되어 표/TSV 형태로 저장되었는가
- 버전 확인을 시도했고 결과(최신 여부 또는 확인 불가 사유)를 보고했는가
- `fields` 출력을 그대로 덤프하지 않고 카테고리별로 요약했는가
- 세 작업의 결과를 하나의 일관된 응답으로 묶어 전달했는가
